# Day 14 — OLED 与网页合体（2026-11-08）

## 目标
把 Day 13 的屏幕接进 Day 12 的完整工程：一个固件同时干三件事——
屏幕显示、网页服务、串口命令。这是"桌面环境检测仪"的雏形。

## 现象
- 屏幕 6 行：标题 / 温度 / 阈值 / 告警状态 / IP / 信号+运行秒数，每 0.5 秒刷新
- 网页照常可用，点色块 RGB 灯跟着变
- 串口 `th 36` 改阈值，屏幕上的 th 那一行立刻跟着变

## 学到什么
1. 一个 loop() 里同时跑 4 个任务：网页（handleClient）、屏幕（500ms）、采样（2s）、呼吸灯（15ms），
   全靠 millis() 错开，谁都不阻塞谁——这就是裸机"任务调度"。
2. OLED 全屏刷新一次 I2C 要传 1KB，400kHz 下约 25ms。所以刷新频率放 500ms，不能放进 15ms 的呼吸灯循环里。
3. 屏幕是被动显示层，数据源还是那套全局变量（threshold / alert / temperatureRead），
   网页和屏幕读的是同一份状态——这就是"一个数据源，多个视图"。
