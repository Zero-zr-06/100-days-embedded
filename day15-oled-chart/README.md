# Day 15 — OLED 温度曲线（2026-11-09）

## 目标
把 Day 8 网页 Canvas 的滚动温度曲线搬到 OLED 上：上半文字、下半折线，
同一个 hist 环形数组喂两个视图（网页 + 屏幕）。

## 现象
- 屏幕上半：温度/阈值两行；下半：从左往右生长的折线，铺满后向右滚动
- 手捂芯片 10 秒，曲线整体上爬
- 网页曲线照常同步滚动

## 学到什么
1. 画图的本质是映射：温度值 → 像素 y 坐标（63 - (v-min)/(max-min)*47），
   时间序号 → 像素 x。网页 Canvas 和 OLED 用的是同一个公式，只是画布从浏览器换成 128x64。
2. 自动缩放：先扫一遍窗口求 min/max，曲线永远占满画布。代价是早期点少时波动被放大。
3. drawLine 连相邻两点。数据点比像素多也没关系，画的是趋势不是精度。
